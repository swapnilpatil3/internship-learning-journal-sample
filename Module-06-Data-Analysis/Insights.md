#  Insights from Data Analysis

##  Objective

To summarize findings and extract meaningful insights from the dataset.

---

##  Dataset Summary

* Dataset contains multiple records with features like Name, Age, Salary
* Some missing values were present
* Duplicate entries were found

---

##  Key Observations

* Most Age values fall within a specific range
* Salary shows variation across different records
* Some values were missing and handled

---

##  Trends Identified

* Certain features show consistent patterns
* Some variables are positively correlated

##  Problems Identified

* Missing values
* Duplicate records

* Filled missing values using mean
* Removed duplicates
* Filtered out outliers

##  Business Impact
