#  Prompt Experiments (AI Coding)

##  Overview

Prompt experiments involve testing different prompts with AI models to understand how prompt design affects output quality.

---

##  Objective

* Improve prompt quality
* Get accurate responses
* Learn how AI behaves with different instructions

---

##  What is a Prompt?

A prompt is the input given to an AI model.

 Example:
"Write a Python program to find prime numbers"

---

##  Why Prompt Experiments?

* Same task → different outputs
* Helps improve accuracy
* Reduces errors in AI responses

---

#  Experiment 1: Basic vs Detailed Prompt

##  Prompt 1 (Basic)

"Write a program to sort an array"

##  Output

* Simple code
* No explanation

---

##  Prompt 2 (Detailed)

"Write a C# program to sort an array in ascending order with step-by-step explanation"

##  Output

* Code + explanation
* Better clarity

---

##  Observation

* Detailed prompts give better results
* More context = better output

---

#  Experiment 2: Role-Based Prompt

##  Prompt

"You are a C# expert. Explain bubble sort with example and code."

##  Output

* Professional explanation
* Structured answer

---

##  Observation

* Role-based prompts improve quality
* AI behaves like assigned role

---

#  Experiment 3: Step-by-Step Prompt

##  Prompt

"Explain how to check prime number step by step"

##  Output

* Clear steps
* Easy to understand

---

##  Observation

* Step-by-step prompts improve learning
* Useful for beginners

---

#  Experiment 4: Constraints Prompt

##  Prompt

"Write a prime number program without using Math.Sqrt"

##  Output

* Custom solution
* Follows constraints

---

##  Observation

* Constraints control output
* Useful for interview questions

---

#  Experiment 5: Few-Shot Prompt

##  Prompt

"Example:
Input: 5 → Output: Prime
Input: 8 → Output: Not Prime

Now check 11"

##  Output

* AI understands pattern

---

##  Observation

* Examples help AI learn pattern
* Improves accuracy

---

#  Experiment 7: Optimization Prompt

---

#  Types of Prompting Techniques

1. Zero-shot → No examples
2. Few-shot → With examples
3. Role-based → Assign role
4. Chain-of-thought → Step-by-step reasoning
5. Instruction-based → Clear instructions

---

#  Best Practices

* Be clear and specific
* Add context
* Use examples
* Give constraints
* Iterate and improve prompts

---

#  Key Learnings

* Prompt quality directly affects output
* Detailed prompts give better results
* Experimentation is necessary
* AI can be used for coding, debugging, and learning

---

# Conclusion

Prompt engineering is a powerful skill in AI development.
By experimenting with different prompts, we can control AI output and improve accuracy.

 Good prompt = Good result
