# Module 07: Data Visualization – Charts

## What are Charts?
Charts are visual representations of data that help in understanding comparisons, trends, and patterns easily. They convert numerical data into graphical form, making it more readable and meaningful.

---

## Types of Charts

### 1. Bar Chart
- Used to compare values between different categories
- Each bar represents a category
- Length of bar shows value

**Example:** Comparing sales of different products

---

### 2. Line Chart
- Used to show trends over time
- Data points are connected with lines

**Example:** Monthly sales growth

---

### 3. Pie Chart
- Represents data in percentages
- Shows proportion of each category

**Example:** Market share of companies

---

### 4. Histogram
- Shows distribution of data
- Groups data into ranges (bins)

**Example:** Distribution of student marks

---

### 5. Scatter Plot
- Shows relationship between two variables
- Each point represents a data value

**Example:** Height vs weight analysis

---

## When to Use Which Chart

- **Bar Chart** → Comparing categories  
- **Line Chart** → Showing trends over time  
- **Pie Chart** → Showing proportions  
- **Histogram** → Showing distribution  
- **Scatter Plot** → Showing relationships  

---

## Features of Good Charts
- Clear title
- Proper labels (X-axis and Y-axis)
- Correct scale
- Simple design
- Easy to understand

---

## Common Mistakes in Charts
- Using wrong chart type
- Too many colors
- Missing labels
- Overcrowded data
- Misleading scales

---

## Key Takeaways
- Charts make data easy to understand
- Choosing the right chart is very important
- Keep charts simple and clear
- Always label your charts properly
